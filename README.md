# Program Data Buku dengan PHP

## Deskripsi

Program ini dibuat untuk menampilkan data 3 buku yang terdiri dari judul, penulis, dan tahun terbit menggunakan dua gaya pemrograman PHP, yaitu prosedural dan Object-Oriented Programming (OOP).

## Daftar File

1. `buku_prosedural.php` — program menggunakan pendekatan prosedural.
2. `buku_oop.php` — program menggunakan pendekatan OOP.



## Tiga Perbedaan yang Saya Rasakan

### 1. Struktur Penulisan Kode

Pada pemrograman prosedural, saya merasa penulisan kode lebih sederhana karena data dan instruksi ditulis secara berurutan. Pada OOP, saya harus memahami konsep class, object, constructor, dan method terlebih dahulu.

### 2. Pengelolaan Data

Pada pendekatan prosedural, data buku disimpan dalam array sehingga mudah digunakan untuk menampilkan beberapa data. Pada OOP, setiap buku dibuat sebagai objek yang memiliki atribut judul, penulis, dan tahun. Menurut saya, pendekatan OOP membuat data lebih terstruktur berdasarkan objeknya.

### 3. Pengembangan dan Pemeliharaan Program

Pada pendekatan prosedural, perubahan program dapat mengharuskan saya mengubah beberapa bagian kode yang berkaitan. Pada OOP, penambahan atau pengembangan fitur dapat dilakukan melalui class dan method sehingga kode lebih mudah dikembangkan ketika program semakin besar.

## Kesimpulan

Berdasarkan praktik ini, saya memahami bahwa pemrograman prosedural lebih mudah dipelajari untuk program sederhana, sedangkan OOP lebih terstruktur dan cocok untuk program yang terus dikembangkan. Keduanya memiliki kelebihan masing-masing dan dapat digunakan sesuai kebutuhan program.
